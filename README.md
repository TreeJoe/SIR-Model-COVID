# COVID-19 Spread: The SIR Model

## Overview

This repository accompanies the paper *Susceptible–Infected–Recovered (SIR) Model: A Simple Framework to Study COVID-19 Spread*, co-authored by S. Bandyopadhyay and Atrijo Roy and published in a college magazine.

The paper combines a theoretical discussion of the Susceptible–Infected–Recovered (SIR) model with exploratory data visualisation related to the COVID-19 pandemic.

The repository contains the research paper, the notebook used for data visualisation, and the three figures selected for the final publication.

## Research Publication

**Title:** Susceptible–Infected–Recovered (SIR) Model: A Simple Framework to Study COVID-19 Spread

**Authors:** Atrijo Roy and Srinjini Bandyopadhyay

**Published in:** Gradient Vol - I

**Publication year:** 2026

* [View the complete magazine](https://drive.google.com/file/d/1vHeuEjs-STtaTOhv4fDMD89EoEgt4rrp/view?usp=drive_link)

The paper presents an introduction to the SIR framework and its application to understanding infectious disease transmission.

## Running the Notebook

1. Clone or download this repository.
2. Obtain the original dataset from its authorised source, subject to the applicable licence.
3. Install the required Python libraries.
4. Update the dataset path in the notebook to point to your local copy.
5. Run the notebook cells to reproduce the visualisations.

The notebook requires access to the original dataset, which is not provided here for licensing restrictions and will not run end-to-end without it.
